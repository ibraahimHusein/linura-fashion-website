LiNURA Fashion Website 👗

Welcome to my LiNURA Fashion Website project!

This is my first project built using Tailwind CSS. I created this website to practice my frontend development skills and learn how to build responsive and modern websites.

🚀 About the Project

LiNURA is a women's fashion website design that showcases clothing products, fashion categories, discounts, and customer testimonials.

This project helped me understand how to use Tailwind CSS utility classes to style and organize a website.

✨ Features

- Responsive navigation bar
- Mobile hamburger menu
- Women's fashion hero section
- Fashion categories
- Product cards with prices
- Add to Cart buttons (UI design)
- Summer discount section
- Customer testimonials
- Footer with contact and navigation links
- Responsive layout for mobile and desktop

🛠️ Technologies Used

- HTML5
- Tailwind CSS
- Font Awesome
- Flexbox
- CSS Grid

📚 What I Learned

- How to use Tailwind CSS utility classes
- How to create responsive layouts
- How to use Flexbox and CSS Grid
- How to style buttons, images, and product cards
- How to use responsive breakpoints such as "lg:"
- How to organize different sections of a website
